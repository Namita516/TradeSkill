# TradeSkill — Skill Exchange Platform

A platform that matches people based on what they know and what they want to learn.

## The Idea
If A knows drawing and wants to learn cooking, and B knows cooking and wants to learn drawing — they get matched automatically. Both teach. Both learn.

## Features
- Skill-based matching algorithm
- Real-time chat
- Video call integration (API based)
- Session switching — A teaches first, then B teaches
- Dual rating system — rated as both teacher and student

## Tech Stack
- React.js
- Node.js
- JavaScript
- MERN Stack
- Video Call API

## How it works
1. User registers and adds skills they have and skills they want
2. Algorithm finds the best match
3. Both users connect via chat
4. Video session starts — first user teaches, then roles switch
5. Both rate each other as teacher and as student
6. Ratings improve match quality over time
